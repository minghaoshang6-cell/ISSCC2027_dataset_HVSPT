# ISSCC2027_dataset_HVSPT
This dataset contains the measured efficiency results of a symbol power tracking (SPT) supply modulator developed for an ISSCC 2027 submission. The measurement data are organized into six groups corresponding to different input- and output-voltage conditions, including 2.5–3 V, 2.5–6 V, 2.5–10 V, 2.5–12 V, 4–10 V, and 4–12 V.
